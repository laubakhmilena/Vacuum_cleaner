# Пылесос Пыслей

**Thought Vacuum**

Милая браузерная arcade/casual-игра, в которой волшебный пылесос собирает хорошие мысли, избегает вредных и ловит золотые бонусы.

</div>

## Об игре

Игрок управляет пылесосом с магической аурой и очищает поток мыслей:

- хорошие мысли увеличивают счёт и серию;
- вредные мысли отнимают жизнь и сбрасывают комбо;
- золотые мысли дают больше очков и активируют случайный бонус;
- заработанные звёзды можно тратить на улучшения, бустеры и скины.

Раунд продолжается, пока у игрока остаются жизни. После завершения показываются итоговый счёт, лучший результат и полученные звёзды.

## Управление

Игра рассчитана на мышь и сенсорный экран.

| Устройство | Управление |
|---|---|
| Компьютер | Перемещайте указатель мыши по игровому полю |
| Телефон или планшет | Ведите пальцем по экрану |
| Интерфейс | Используйте кнопки меню, магазина, звука и перезапуска |

При потере фокуса окна или переключении вкладки активный раунд автоматически приостанавливается.

## Игровые правила

| Объект | Эффект |
|---|---|
| Хорошая мысль | `10 × комбо` очков |
| Золотая мысль | `50 × комбо` очков и случайный бонус |
| Вредная мысль | Потеря одной жизни и сброс комбо |
| Каждые 5 хороших мыслей | Повышение комбо на 1 |
| Максимальное комбо | `x5` |
| Начальное количество жизней | 3 |
| Награда за результат | 1 звезда за каждые полные 100 очков |

При активном удвоении очков награда за пойманные мысли умножается на `x2`.

## Улучшения

В мастерской доступны постоянные улучшения:

- **Радиус втягивания** — увеличивает область действия ауры.
- **Длительность бонусов** — продлевает магнит, замедление и двойные очки.
- **Запасное сердце** — добавляет одну жизнь в начале раунда.

## Бустеры

Перед следующим раундом можно активировать:

- **Умный магнит** — притягивает хорошие и золотые мысли и отталкивает вредные.
- **Щит от плохой мысли** — один раз блокирует вредную мысль.
- **Звёздный старт** — начинает раунд с временным множителем `x2`.

Количество каждого бустера ограничено тремя экземплярами.

## Скины

Доступны четыре варианта ауры:

- голубая;
- розовая;
- золотая;
- космическая.

Скины изменяют только внешний вид и не влияют на игровой баланс.

## Локализация

Игра поддерживает:

- русский язык;
- английский язык.

Язык определяется автоматически по окружению Yandex Games или языку браузера. Для локальной проверки язык можно передать параметром URL:

```text
?lang=ru
?lang=en
```

Пример:

```text
http://localhost:8000/?lang=en
```

## Локальный запуск

### Вариант 1 — Python

Откройте терминал в корне проекта:

```bash
python -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000
```

На некоторых системах команда называется:

```bash
python3 -m http.server 8000
```

### Вариант 2 — Visual Studio Code

Установите расширение **Live Server**, откройте `index.html` и выберите **Open with Live Server**.

> При локальном запуске Yandex Games SDK и настоящие рекламные показы могут быть недоступны. Полную интеграцию необходимо проверять в среде Yandex Games.

## Хранение прогресса

Локальный прогресс сохраняется в браузере через `localStorage` под ключом:

```text
thoughtVacuumProgress.v1
```

Сохраняются:

- лучший результат;
- звёзды;
- улучшения;
- бустеры;
- купленные и выбранный скин;
- ежедневная награда и задания;
- настройка звука.

Очистка данных сайта в браузере удалит локальный прогресс.
